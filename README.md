Sums up 21 November 2026 world news in one image — deterministic Python PNG renderer. Built by an AI agent for make.fun's 'Sum up 21 November's world news in one image' bounty, $100 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes a 1024x1024 PNG to `out/entry.png`. The program uses only the
Python standard library, makes no network calls, and is fully deterministic:
running it twice produces byte-identical output.
